# Dashboard de Análisis de Ventas 📊

Proyecto en Python para el análisis de ventas a partir de múltiples archivos CSV.
Incluye limpieza de datos, generación de métricas y visualizaciones, y un dashboard interactivo con Tkinter.

## 🚀 Características

- **Análisis temporal**: Ventas por mes, día, hora y tendencias
- **Geolocalización**: Mapas de ventas por estado y top ciudades
- **Productos**: Identificación del producto estrella y análisis de factores de éxito
- **Eventos especiales**: Impacto de días festivos en las ventas
- **Productos complementarios**: Análisis de canasta de compra
- **Exportación de datos**: CSV, Excel y PDF con los análisis visibles
- **Filtros interactivos**: Por estado, ciudad, mes, día, categoría y rango de fechas

## 🛠️ Tecnologías utilizadas

- Python 3.14
- Pandas (análisis de datos)
- Plotly (visualizaciones interactivas)
- Dash (framework web)
- Dash Bootstrap Components (diseño responsive)
- ReportLab (generación de PDF)
- XlsxWriter (exportación a Excel)
